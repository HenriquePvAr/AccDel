# Início rápido — cozinha

1. Entre no Admin da cozinha e confirme loja/estação.
2. Mantenha a fila ordenada; abra o pedido e confira itens, adicionais e observações.
3. Inicie preparo quando aplicável e marque pronto apenas quando todo o lote estiver pronto.
4. Adições aparecem como novo lote e via `ORDER_ADDITION`; não misture com o cupom inicial.
5. Se a tela reconectar, confira o estado atual antes de tocar novamente.

Impressora offline ou cupom ausente: olhe a fila de impressão/agent; não marque o pedido de novo para “forçar”. Resultado desconhecido exige conferir fisicamente se imprimiu. Com tela indisponível, use a fila/cupom manual acordado e reporte pedido, estação, horário e erro ao suporte.
